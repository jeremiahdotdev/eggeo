## Test Instructions

1. Sign in with the demo account.
2. On Home, select the demo event.
3. Open Find and scan a demo egg QR code.
4. Open Map and allow location access to see nearby eggs.
5. Open Events to create or review event QR codes.
6. Open User and verify Delete Account is available behind a destructive confirmation.

## Review Notes

Eggeo uses camera access only to scan QR codes. Eggeo uses location access to hide eggs and show nearby eggs on the map. Account deletion permanently removes the signed-in user's account, event memberships, owned events, owned eggs, and score records.
